# 단음 뭉개짐 구분 테스트

`tone_test.elf`는 곡 재생과 별개인 C 진단 펌웨어입니다. 기존 `concert.elf`는 유지합니다.

1. 보드 전원을 끈 상태에서 부저 하나의 신호를 **PB4 / D5 / CN9-6**에, 접지를 GND에 연결합니다. 기존 3번 부저 자리입니다. 다른 부저는 분리해서 비교합니다. 모듈의 전원 연결은 기존 구동 방식에 맞춥니다.
2. STM32CubeProgrammer에서 `tone_test.elf`를 업로드하고 RESET합니다. 초기에는 무음입니다.
3. B1을 짧게 눌렀다 놓을 때마다 **1000Hz → 2000Hz → 500Hz → 무음** 순서로 바뀝니다. 소리가 켜지면 LD2도 켜집니다.
4. 각 단계는 버튼을 다시 누를 때까지 일정한 주파수를 유지합니다. 자동 음표 전환이나 반복적인 PWM 초기화가 없습니다.

기존 예제의 PB4/TIM3 방식으로 1MHz 카운터와 50% 듀티를 사용합니다. 나머지 7개 출력은 LOW입니다. 명목 주기는 각각 1ms, 0.5ms, 2ms입니다. 실제 보드/부저 소리는 아직 검증하지 않았습니다.

## 관찰할 내용

- 단음 테스트는 깨끗하고 곡에서만 깨짐: 음역, 재타건 및 음 교체를 우선 조사합니다.
- 500Hz에서 거칠고 2000Hz에서는 또렷함: 부저의 음역 특성이 관여할 가능성이 있습니다.
- 주파수를 바꿔도 음높이가 거의 같고 지직거리는 정도만 달라짐: 자체 발진형 부저 가능성을 확인해야 합니다.
- 모든 주파수에서 불규칙한 잡음: 접촉, 공통 접지, 부하를 연결한 GPIO 파형과 구동 전류를 확인해야 합니다.

사각파의 일정한 날카로운 음색과 불규칙하게 끊기거나 떨리는 잡음은 구분해야 합니다. 부저 종류/구동 부하가 확인되지 않았으므로 테스트 결과만으로 원인을 단정하지 않습니다. GPIO 직결의 전기적 적합성이 확인된 것은 아닙니다.

빌드: `make tone-test`. 곡 연주로 복귀하려면 `concert.elf`를 다시 업로드합니다.
